# Ultima I Korean Localization — M261

M261 restores the original MONDAIN final-arena input presentation: Attack remains a live prompt-bearing row, the selected direction is printed on that same row, and valid attacks execute source sound(7) before resolution. Successful avatar movement now presents the moved frame and runs source sound(4) before Mondain AI. Evil-gem, transient flame/magic, and Mondain sprite animation advance on the original 3-BIOS-tick keyboard-poll cadence instead of once per command.
