# M262 — MONDAIN framed-popup text color

M262 restores the original light-cyan text color for the framed MONDAIN popups shown before and after the final encounter. The four Time Machine narration pages, the victory popup, and the defeat popup use EGA light cyan RGB(85,255,255).

The RGBW labels on the first Time Machine page use the same popup text color. The four BIOS gem glyphs retain their original red/green/blue/white colors. The NIF ending restart line is not part of the framed popup and remains white.

Historical M256 was updated so it no longer pins the obsolete white popup text implementation.
