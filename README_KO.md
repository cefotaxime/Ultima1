# Ultima I 한글화 clean-room — M255

M255는 `MONDAIN.EXE`의 타임머신 첫 안내 페이지를 원본처럼 독립된 전체 화면으로 복원하고, 승인된 한글 9행 번역을 적용한다. `R/G/B/W` 원문 행은 별도의 행을 추가하지 않고 `붉은색 / 녹색 / 푸른색 / 흰색` 한 행으로 교체한다. 네 색상의 기준 위치는 원본 열 12/17/22/27을 유지하며, `붉은색`의 `은`이 기존 `R` 위치에 오도록 픽셀 단위로 배치한다. 아래 행의 네 색 보석 표식도 원본 위치를 유지한다.

`locked in`은 `당신은 기체 안에 갇혀 있어`로 번역한다. 원본 대기 루틴과 같이 이 페이지는 Space 또는 Return 입력까지 화면을 독점하며, 그 동안 일반 프레임/상태창/명령 로그/Mondain AI는 진행하지 않는다. M254 사망·부활 시간축, M253 하이퍼점프 blocking-row, M252 하이퍼점프 시간축, M246 오디오 경로는 그대로 유지한다.
