# Ultima I 한글화 clean-room — M260

M260은 몬데인 최종전의 전투 문구를 승인된 한글 번역으로 교체하고, 승리/패배 연출을 원본의 **커맨드줄 + 프레임 팝업** 구조로 복원한다.

패배 시 `당신은 사망하였습니다!`가 먼저 아래 커맨드줄에 출력되고, 위쪽 팝업에 `당신은 마술사 몬데인에게 / 패배하였습니다!`와 `우주의 운명은 끝입니다!`가 표시된다. 승리 시 마지막 공격/몬데인 사망 문구는 커맨드줄에 남고, 위쪽 팝업에 `승리하였습니다!`가 표시된 뒤 별도의 NIF 엔딩 단계로 넘어간다.

기묘한 영창, 세 종류 주문, 명중/빗맞음, 능력치 감소, 보석 파괴와 화상, 가지기-보석, 탐지하기 결과 등 몬데인 전투 문구도 모두 요청 문구로 반영했다.

타임머신 두 번째 페이지의 첫 문단도 `불빛이 춤을 추기 / 시작합니다.`로 4행화했으며, 세 문단 사이의 빈 줄은 각각 정확히 1줄이다.
