# Ultima I 한글화 clean-room — M256

M256은 타임머신 첫 안내 화면을 원본 `MONDAIN.EXE`의 팝업 구조로 다시 맞춘다.

원본은 전체 화면을 지우지 않는다. source 좌표 `(22,15)..(300,143)`만 검게 지운 뒤 `(25,18)..(297,140)`에 파란 팝업 테두리를 그리고, 바깥의 울티마 프레임과 아래 명령창/상태창은 그대로 남긴다. M255의 전체 화면 modal 처리는 잘못된 복원이라 폐기한다.

승인된 9행 한글 문구는 그대로 유지하되 일반 문장은 팝업 중앙에 정렬한다. RGBW 기준 열은 원본 BIOS column `12/17/22/27`을 유지하고, `붉은색`의 `은`이 기존 `R` 위치에서 시작하도록 배치한다. 네 색 보석 표식도 원본 row 7 위치를 유지한다.

계속 입력 안내는 상단 팝업 내부가 아니라 원본처럼 아래 명령창에 표시한다. 팝업이 닫히기 전에는 이후 몬데인 조우 문구를 로그에 미리 넣지 않는다.

구식 audit 호환도 갱신했다. M97의 Ready exact-source 표현식은 그대로 보존하고, M255 audit은 M256 구조를 허용하도록 수정했으며 M256 전용 popup audit을 추가했다.
