# Ultima I 한글화 clean-room — M261

M261은 몬데인 최종전의 입력/효과음/애니메이션을 원본 방식으로 복원한다. Attack 대기 줄은 파란 `>`가 있는 현재 커맨드 줄에 유지되고 커서는 같은 줄 끝에서 방향을 기다린다. 방향 입력도 같은 줄에 출력한 뒤 원본 `sound(7)`을 실행하고 공격 판정을 진행한다. 최종 전투장의 아바타 이동은 새 위치 화면을 먼저 표시한 다음 원본 `sound(4)`를 재생한다. 보석, 불길/마법 효과, 몬데인 프레임은 턴당 1회가 아니라 원본 키보드 대기의 3 BIOS tick 주기로 계속 애니메이션된다.
